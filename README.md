# 晨间新知

一个无需构建工具的静态网页，展示每天北京时间 08:00 更新的 AI 与科技生活简报，以及考研英语每日阅读。

## 本地打开

直接双击 `index.html` 即可。也可以在本目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据规则

- 内容位于 `data/issues.js`，最新日期排在最前或最后均可，页面会自动排序。
- 只保留最近 7 个自然日。
- 每一条事实信息必须包含可直接打开的官方公告、官方产品页或原文链接。
- 媒体报道只能作为补充来源；涉及产品功能、价格、免费额度和领取方式时，必须优先引用官方页面。
- 无法核验发布日期、免费限制或使用范围时，不得填入推测性结论。
- 英语文章必须免费阅读全文、发布时间在近 14 天内，并附原文链接。

## AI 页面结构

- `updates`：今天新发布或新上线的内容，只回答“更新了什么、学生有什么用、怎么使用、费用与限制”。
- `deals`：免费额度、学生优惠和限时活动，必须核验领取入口、限制与截止时间。

AI 条目固定字段：`event → howTo → free → impact → source`。

## 公网发布

本站是纯静态页面，可直接发布到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。根目录已经包含 `404.html` 和 `netlify.toml`，无需安装依赖或设置构建命令。

在没有托管账号时，可运行 `start-public.ps1` 创建 Cloudflare 官方临时公网地址。该地址要求本机持续开机联网，且 Cloudflare 官方说明 Quick Tunnel 不提供可用性保证，适合临时访问而非长期生产托管。运行 `stop-public.ps1` 可关闭公网访问。
